# VPN Manager Bot

Telegram-бот для управления доступом к self-hosted VPN (Xray, VLESS + Reality) через REST API панели [3X-UI](https://github.com/MHSanaei/3x-ui) v3.
Пользователь подаёт заявку в боте, администратор одобряет её одной кнопкой, и бот сам создаёт клиента в панели и присылает ключ и QR-код.

Бот сделан для небольшой сети на 30–40 пользователей. Без него каждого клиента приходится вручную заводить в панели, рассылать ключи в личку и самому следить за сроками.

**Стек:** Python 3.12, aiogram 3, httpx (async), aiosqlite, pydantic-settings, qrcode, Docker, pytest, Ruff, GitHub Actions.

## Возможности

Пользователь:
- `/start` открывает заявку на доступ. Кнопка «Запросить доступ» отправляет её всем администраторам.
- `/key` присылает ссылку `vless://` и QR-код для v2rayNG, Hiddify, Streisand и других клиентов.
- `/status` показывает срок действия и израсходованный трафик.
- За N дней до окончания доступа бот присылает напоминание.

Администратор:
- Одобряет или отклоняет заявку кнопкой.
- `/users` выводит всех пользователей с оставшимся сроком и трафиком. Трафик запрашивается у панели параллельно.
- `/add <tg_id> [дней]`, `/extend <tg_id> <дней>`, `/revoke <tg_id>`.

## Как устроено

```
bot/
  xui.py         асинхронный клиент REST API 3X-UI (Bearer-токен): создание, изменение и удаление клиентов, трафик
  links.py       сборка vless://...?security=reality из настроек инбаунда и генерация QR
  service.py     бизнес-логика: выдать, продлить, отозвать доступ
  db.py          SQLite (aiosqlite): связь Telegram ID с клиентом в панели
  reminders.py   фоновая задача с напоминаниями об окончании срока
  handlers/      роутеры aiogram для пользователей и администраторов (фильтр IsAdmin)
```

- Срок действия хранится **в самой панели** (`expiryTime`), поэтому Xray отключает клиента даже тогда, когда бот не запущен.
- Параметры ссылки (публичный ключ, SNI, shortId, порт) бот каждый раз берёт из настроек инбаунда в панели. Если на сервере сменить ключи Reality, бот начнёт выдавать новые ссылки без изменений в коде.
- Бот ходит в панель по API-токену, а не по логину и паролю администратора. Токен можно отозвать в панели в любой момент.
- Telegram ID пользователя записывается в поле `tgId` клиента, так что в панели сразу видно, чей это ключ.
- Ошибки панели перехватывает общий обработчик aiogram, и пользователь получает понятное сообщение.
- Продление считается от текущей даты окончания, а если доступ уже истёк, то от сегодняшнего дня.

## Запуск

1. Создать бота у @BotFather и узнать свой Telegram ID.
2. В 3X-UI должен быть инбаунд VLESS + Reality (TCP). Его id виден в списке инбаундов. Там же, в настройках, создать API-токен со scope `admin`.
3. Заполнить настройки и запустить:

```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f bot
```

База SQLite лежит в volume `bot_data`.

## Разработка

```bash
pip install -r requirements-dev.txt
ruff check . && ruff format --check .
pytest
```

В тестах вместо настоящей панели работает поддельный HTTP API 3X-UI (`httpx.MockTransport`). Так проверяются авторизация по токену, создание, продление и удаление клиентов, обработка ошибок панели, сборка ссылки и напоминания.
